# public/

Static assets served from the site root (`/`).

| File | Purpose | Replace with |
| ---- | ------- | ------------ |
| `og-image.svg` | Default Open Graph / Twitter card image referenced by `components/SEOHead.tsx`. | Your branded 1200×630 image. PNG/JPG is recommended for the widest social-platform support — drop in `og-image.png` and update the default `image` in `SEOHead.tsx`. |

> The app icon/favicon lives at `app/icon.svg` (Next.js App Router convention).
> Add additional placeholder images here as your tools grow (screenshots,
> illustrations, logos, etc.).
